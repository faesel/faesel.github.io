1d:T130b,<h1>Introduction</h1>
<p>If you&#39;ve been using GitHub Copilot CLI, you&#39;ll know it stores a surprising amount of data locally — session metadata, conversation history, token usage, tool calls, checkpoint snapshots. It&#39;s all sitting in <code>~/.copilot/session-state/</code>, but there&#39;s no built-in way to browse or make sense of it.</p>
<p>I wanted to understand my usage patterns. How many sessions am I running? Which repos am I spending the most time in? How close am I getting to the 128K context window? So I built GridWatch — a desktop app that reads all of this local data and turns it into a real-time dashboard.</p>
<p>I actually vibecoded this entire project in just 2 days. It&#39;s quite amazing how far Copilot has come. I do still need to test out the Windows version of the app, the mac version however works a treat!</p>
<h1>What it does</h1>
<p>GridWatch scans the Copilot CLI session directories and parses <code>workspace.yaml</code>, <code>events.jsonl</code>, rewind snapshots, and log files to surface:</p>
<ul>
<li><strong>Session list</strong> with search, tag filtering, and status indicators<br>(active/recent/old), captures every message you sent in a session, with model badges showing whether it was a premium request.</li>
<li><strong>Token usage charts</strong> — line graphs tracking token consumption over time, bar<br>charts for daily usage, and per-session peak utilisation</li>
<li><strong>Activity heatmap</strong> — a GitHub-style contribution grid showing when you&#39;re most<br>active with Copilot</li>
<li><strong>Insights</strong> — Gives you insights on your prompts and gives you suggestions on how to improve them. You also get scored!</li>
<li><strong>Session Transfers</strong> — Lets you transfer the context of a session from one session to the other.</li>
</ul>
<p>You can see more screenshots <a href="https://github.com/faesel/gridwatch?tab=readme-ov-file#-screenshots">here</a></p>
<p>My favorite feature of all is the session transfers. If you do planning in one session and then you want to transfer it to another session, there&#39;s not really a way to do this. Gridwatch has these feature and works by compacting a plan of the session into an MD file and then transfers it into the other session copilot folder <code>~/.copilot/session-state/8b78b4f4-5804-4671-8540-5648f92786ed/transfer-2026-02-28T08   -54-40.md</code></p>
<p><img src="//images.ctfassets.net/wjg1udsw901v/iegRPlmLBZ6ZmuyYDrcE5/1ea3a2dc53cbd5a5f539b9e70a29c847/image.png" alt="Gridwatch - session transfer"></p>
<p>Everything runs locally. GridWatch only reads Copilot&#39;s files and never sends data anywhere. For insights there is a requirement for a github classic token.</p>
<h1>The stack</h1>
<p>I went with <strong>Electron + React 19 + TypeScript + Vite</strong> for the app shell, I mostly went with electron because I have past experience with the framework and I know React extensively. Charts are rendered with <strong>Recharts</strong>. Styling uses CSS Modules with a set of CSS custom properties for the theme.</p>
<p>The architecture follows the standard Electron process model — the main process handles all file system access and IPC, the preload script exposes a typed API bridge, and the renderer is a pure React app with no direct Node.js access.</p>
<h1>Design choices</h1>
<p>The visual theme is inspired by Tron — neon cyan and electric blue accents on near-black backgrounds. Why tron? well ... all these AI processes felt like the programs from the movies.</p>
<p>Check out the red programs theme:<br><img src="//images.ctfassets.net/wjg1udsw901v/3KmA82xZPtngfVIMi1FAzf/0051c3b23575d76a48829d76006050a9/image.png" alt="Gridwatch - red programs theme"></p>
<h1>Optional Credentials</h1>
<p>The app does store the users API key (git classic token) which is used for analysing the users prompts and how good they are.</p>
<p><img src="//images.ctfassets.net/wjg1udsw901v/JgnBiJv0zBlJhilSvrb7a/bcc73ae99e6a4d126552c95591ba0634/image.png" alt="Gridwatch - Github api access token"></p>
<p>For security, the preload script only exposes specific typed methods (no generic <code>ipcRenderer</code> access). All IPC handlers validate session IDs as UUIDs and guard against path traversal. API keys are encrypted using Electron&#39;s <code>safeStorage</code> (macOS Keychain / Windows DPAPI) rather than stored in plaintext.</p>
<p>The credentials are not needed if your not going to make use of the insight tab.</p>
<h1>What&#39;s next</h1>
<p>The tool is free to use, but I might extend it so that it gets approved in the Mac and Windows app stores and just becomes readily available for any engineer to use for free.</p>
<p>The project is open source — check it out on <a href="https://github.com/faesel/gridwatch">GitHub</a> if you&#39;re interested. Feedback and feature ideas are welcome!</p>
